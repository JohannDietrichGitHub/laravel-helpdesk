# Glossaire

- **Inertia** : couche qui permet à Laravel de piloter des pages React avec des réponses serveur et des navigations sans API REST dédiée.
- **Prop** : donnée envoyée par Laravel à une page React.
- **Form Request** : classe Laravel qui valide une requête et peut autoriser son exécution.
- **Policy** : classe Laravel qui décide si un utilisateur peut agir sur une ressource.
- **Eager loading** : chargement anticipé de relations Eloquent pour éviter les requêtes N+1.
- **Queue** : file de jobs exécutés hors de la requête HTTP.
- **Scheduler** : planificateur de commandes Laravel.
- **Event** : fait métier publié par l’application.
- **Listener** : réaction à un événement.
- **Sanctum** : mécanisme Laravel utilisé ici pour les tokens API.
- **Wayfinder** : génération de helpers TypeScript à partir des routes et contrôleurs Laravel.
- **Flash message** : message temporaire stocké en session puis partagé à la page suivante.
- **Soft delete** : suppression logique ; la ligne reste en base mais est exclue des requêtes normales.
